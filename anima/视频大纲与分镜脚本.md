# 《从磁场到波形》视频大纲与分镜脚本

## 视觉总纲

- **片名**：从磁场到波形 / MEGKNOB SIGNAL PIPELINE
- **目标时长**：约 2 分 10 秒
- **画幅**：16:9，1920 × 1080，30 FPS
- **风格**：深蓝黑工程背景、示波器网格、青色信号流、黄色扫描状态、洋红磁场；在写实硬件示意与抽象数据可视化之间切换。
- **叙事规则**：每一个关键函数构成一个分镜。画面左侧显示函数名和精简后的真实代码，右侧让代码正在操作的对象同步运动；被执行的关键行用黄色高亮。
- **声音**：本版不嵌入旁白与音乐，保留清晰的纯视觉节奏，便于后续配音和剪辑。

## 分镜 00｜引子：一条按键事件的旅程（0:00–0:09）

**画面**

黑场中一枚磁轴按键出现。按键下压，洋红磁力线被压缩，一颗青色光点从传感器诞生，依次穿过 `MUX → ADC → FRAME → USB → PLOT` 五个节点。片名从光点轨迹中显现。

**字幕**

```text
从磁场到波形
24 channels · one live data stream
```

**目的**

先给观众建立完整流水线，再逐层放大每个环节。

---

## 分镜 01｜物理层：磁铁靠近，电压下降（0:09–0:22）

**函数 / 概念**：`kscan_adc_mux_pressed()`

**左侧代码**

```c
return was_pressed
    ? sample_mv < 1400
    : sample_mv < 900;
```

**右侧动画**

- 键帽与磁铁向下移动；
- 霍尔传感器输出曲线从约 1.8 V 平滑降至约 0.7 V；
- 900 mV 按下线与 1400 mV 释放线形成黄色滞回带；
- 电压穿过 900 mV 后，状态灯由 `RELEASED` 变为 `PRESSED`；
- 回程时直到越过 1400 mV 才释放。

**核心信息**

磁轴首先产生的是连续模拟电压，按键状态只是对这条曲线的一种解释。

---

## 分镜 02｜寻址：三片 4051，一组地址线（0:22–0:38）

**函数**：`kscan_adc_mux_set_address()`

**左侧代码**

```c
changed = current_address ^ address;
gpio_pin_set_dt(...);
k_busy_wait(10);
```

**右侧动画**

- 三片 U26/U27/U28 并排，每片有 Y0–Y7 八个输入；
- 三根共享地址线 S0/S1/S2 从 MCU 扇出到三片芯片；
- 地址按 Gray 码 `000, 001, 011, 010, 110, 111, 101, 100` 前进；
- 每一步只有一根地址线闪黄；
- 三片芯片同编号的 Y 通道同时亮起；
- 右下角出现 `settle 10 µs` 的短暂等待环。

**核心信息**

三片 8 选 1 MUX 并行工作：一次选址同时得到三条模拟路径，八次选址覆盖 24 通道。

---

## 分镜 03｜采样：一次 ADC batch read，拿到三路（0:38–0:52）

**函数**：`kscan_adc_mux_read_channels()`

**左侧代码**

```c
adc_read(adc, &batch_seq);
samples_mv[row] = samples[index];
adc_raw_to_millivolts_dt(...);
```

**右侧动画**

- 三条模拟电压进入 nRF52840 SAADC；
- 12-bit 量化阶梯从模拟波形上展开；
- 三个原始整数同步落入 DMA buffer；
- 数值转换为 `mV` 标签；
- 参数依次出现：`12 bit`、`3 µs`、`0.6 V × 6`、`no oversampling`。

**核心信息**

每个 MUX 地址只调用一次 ADC 批量读取，三路公共端一起采样并转换成毫伏。

---

## 分镜 04｜总扫描：8 × 3 = 24（0:52–1:08）

**函数**：`kscan_adc_mux_read()`

**左侧代码**

```c
for (order = 0; order < 8; order++) {
    col = gray_order[order];
    set_address(col);
    read_channels(samples_mv);
    voltages_mv[row * 8 + col] = sample_mv;
}
```

**右侧动画**

- 3 × 8 数据矩阵出现；
- 黄色扫描列按 Gray 码位置跳转；
- 每到一列，同时填入三颗青色数据点；
- 数据最后按 row-major 顺序被拉直为 24 格：`U26 Y0..Y7 | U27... | U28...`；
- 角标显示 `1216 scans/s`、`0.822 ms / scan`。

**核心信息**

物理扫描顺序是 Gray 码，存储与传输顺序仍是稳定的 Y0–Y7，因此上位机不需要理解扫描优化。

---

## 分镜 05｜封包：把 24 个毫伏值变成 62 字节（1:08–1:25）

**函数**：`hall_stream_enqueue()` 与 `hall_stream_crc16()`

**左侧代码**

```c
frame.magic = {'M', 'K'};
frame.version = 3;
frame.samples_mv[i] = voltages_mv[i];
frame.crc = crc16(frame, 60);
```

**右侧动画**

- 62 格字节带从左向右组装；
- 分区依次上色：`MK`、版本/类型/模式/数量、序列号、微秒时间戳、48 字节样本、CRC；
- 24 个电压块压缩为小端字节对；
- CRC 扫描光束越过前 60 字节，最后两格锁定；
- 队列中出现 4 个帧槽；第五帧到来时，最旧帧淡出并由新帧补位。

**核心信息**

固定长度与魔数方便同步，序列号检测丢帧，CRC 负责完整性；满队列丢旧帧以保护采样实时性。

---

## 分镜 06｜发送：采样线程不等 USB（1:25–1:37）

**函数**：`kscan_adc_mux_uart_callback()`

**左侧代码**

```c
sent = uart_fifo_fill(uart,
    bytes + tx_offset,
    sizeof(frame) - tx_offset);
```

**右侧动画**

- 扫描环与发送环分成上下两条独立轨道；
- 上方扫描环保持匀速产生帧；
- 下方发送线程从消息队列取帧；
- DTR 开关亮起后，62 字节帧被一次批量推入 CDC ring buffer；
- USB 线缆中的字节光点流向电脑。

**核心信息**

中断驱动批量发送将传输从逐字节 API 瓶颈提升到超过 1000 data fps。

---

## 分镜 07｜解码：从任意字节流中重新找到帧（1:37–1:53）

**函数**：`decode_frames()`

**左侧代码**

```python
start = buffer.find(b"MK")
if crc16(raw[:-2]) != crc:
    del buffer[0]
    continue
FRAME.unpack(raw)
```

**右侧动画**

- 一条混有噪声字节的流进入接收缓冲区；
- 取景框寻找 `M K`；
- 第一帧 CRC 变绿并解包成字段；
- 一帧故意显示红色 CRC，解析器只滑过一个字节后重新同步；
- 24 个小端整数展开为 24 根带数值的通道条。

**核心信息**

魔数负责定位，固定 62 字节负责切帧，CRC 防止错误数据进入绘图链路。

---

## 分镜 08｜绘图：毫伏最终成为实时曲线（1:53–2:08）

**函数**：`SerialReader.run()` 与 `ScopeWindow.redraw()`

**左侧代码**

```python
chunk = device.read(512)
pending.extend(decode_frames(buffer))
curve.setData(x, data[:, ch] / 1000.0)
```

**右侧动画**

- 串口线程、64 帧有界队列、25 FPS GUI 三层结构依次出现；
- 24 路波形从右侧实时生长；
- 其中一路随按键下压产生明显低谷；
- 数据过密时点云抽稀为约 1000 点，但峰值轮廓保留；
- 指标板显示 `RX 1171 fps`、`72.9 kB/s`、`jitter 0.040 ms`。

**核心信息**

采样频率和绘图刷新率解耦；有界队列与降采样让画面优先保持“现在”。

---

## 分镜 09｜收束：同一颗信号点走完整条链（2:08–2:18）

**画面**

镜头拉远，之前的模块组成完整横向管线：

```text
MAGNET → HALL → 4051 × 3 → SAADC → 24 × mV → 62 B → USB CDC → PYTHON → PLOT
```

一颗光点再次从按键出发，穿过整条管线，最终成为波形上的一个亮点。随后 24 条曲线汇聚为片尾字样。

**片尾字幕**

```text
ONE PRESS · 24 CHANNELS · 1216 SCANS/S
MEGKNOB / ZMK SIGNAL PIPELINE
```
